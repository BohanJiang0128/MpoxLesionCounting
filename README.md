# Lesion Segmentation and Analysis for JMI Publication

This repository contains code used in our Journal of Medical Imaging (JMI) publication for training and analyzing lesion segmentation networks. The structure is divided into two main components:

- `training/`: Scripts and information related to network training.
- `analysis/`: Notebooks and scripts for performance evaluation and visualization.

## Repository Structure

```
.
├── training/         # Network training code
├── analysis/         # Performance evaluation and plotting
├── README.md         # Top-level documentation
├── training/README.md
├── analysis/README.md
```
